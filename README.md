# 마이플래너 (MyPlanner)

도착해야 하는 시간만 넣으면, 이동수단에 맞춰 **거꾸로 계산해서 기상·출발 시간을 알려 주고 알람으로 깨워 주는** 전 국민용 플래너입니다.
직장인·자영업자·주부·학생 누구나 쓸 수 있도록 만들었고, 버디플래너(골프)·매니저플래너(엔터 매니저)의 역산 타임라인 구조를 이어받았습니다.

## 주요 기능
- **6가지 이동수단**: 버스·지하철, 자가용, 택시, 도보, 기차, 비행기
- **실제 경로 가져오기**
  - 버스·지하철 → ODsay (노선번호·환승·정류장 수·요금, 경로 후보 여러 개 중 선택)
  - 자가용·택시 → 티맵 (도착 시각 기준 예측 교통)
  - 도보 → 티맵 보행자 경로
  - 기차·비행기 → 예매한 열차/항공편 시각 입력 + 역·공항까지 가는 경로 자동 조회 (승강장 15분, 국내선 40분, 국제선 150분 전 도착)
- **역산 계산**: 약속 시간 − 여유 − 이동(+대기/주차) − 준비 = 기상 시간
- **알림 4종**: 전날 밤 9시 미리 안내 · 기상 알람 · 출발 10분 전 · 출발 알람
- **전체 화면 기상 알람** (안드로이드): 기상·출발 알람은 잠금 화면 위로 알람 화면이 뜨고, 끌 때까지 소리 반복(최대 3분).
  [알람 끄기] [5분 뒤 다시] [일정 보기] 버튼, 휴대폰 사용 중엔 상단 알림에서 바로 끄기/5분 뒤. 재부팅해도 알람 유지.
- **반복 일정**: 매일 · 평일 · 요일 선택, 공휴일 쉬기(대체공휴일 포함), 종료일. 회차별로 '이 날만 시간 바꾸기 / 건너뛰기', '이 날부터 반복 끝내기'
- **아침 실시간 재계산** (자가용·택시, 역·공항까지 차로 가는 구간):
  - 앱이 꺼져 있어도 **기상 20분 전·출발 30분 전**에 티맵 실시간 교통을 다시 확인
  - 5분 이상 막히면 출발·기상 알람을 당기고 "길이 막혀요 — 15분 일찍 출발하세요" 알림, 늦어도 되면 출발 알람만 미룸 (기상은 그대로)
  - 이미 늦었으면 "지금 바로 출발하세요", 앱을 열 때도 출발 4시간 안의 일정은 자동 재계산
  - 실시간 값은 그날 회차에만 적용 (반복 일정의 다른 날엔 영향 없음)
- **백그라운드 자동 예약**: 앱이 45일치 계획을 폰에 넘기면, 폰이 3일치씩 예약하고 매일 새벽 스스로 보충 → 앱을 오래 열지 않아도 반복 알람이 계속 울림
- **받은 문자로 일정 만들기**: KTX·SRT 승차권, 항공권(국내·국제), 병원 예약, 약속 문자를 붙여넣으면 날짜·시각·역/공항·장소·열차/편명·좌석·"○분 전 도착"까지 자동 채움. 휴대폰 안에서만 해석. 안드로이드는 문자 앱의 **공유 → 마이플래너**로 바로 등록
- **날씨 반영**: 출발 시각 전후 예보가 비·많은 비·눈이면 이동수단별로 여유를 더함 (예: 자가용 비 +15%, 눈 +40%), 전날 밤·기상 알람에 "우산 챙기세요"
- **버스 실시간 도착**: 출발 30분 전부터 첫 정류장의 실시간 도착을 보고 "341번이 08:21에 와요 — 08:13에 나가면 딱 맞아요" / "다음 버스가 늦어 약 9분 늦을 수 있어요". 앱이 꺼져 있어도 **출발 15분 전** 폰이 확인해 알림, 앞 버스를 타야 하면 출발 알람을 당김 (ODsay 실시간 API · 서버 함수 필요)
- **홈 화면 위젯** (안드로이드): 다음 일정의 기상·출발·도착(탑승) 시각과 날씨·실시간 교통 한 줄, 누르면 그 일정으로
- **AI 비서** (PRO 핵심): 말·글로 "내일 10시 아산병원 가야 돼" → 경로·기상·출발을 계산한 큰 확인 카드 → 저장하면 알람까지. 일정 질문·시간 변경(전후 비교)·하루 건너뛰기, 여러 일정 한 번에, "회사"·"엄마 집" 기억, 가족에게 같이 보내기, 마이크·소리로 읽기. 저장은 항상 사용자 확인 후 (서버 함수 `myplanner-ai`, Claude). 무료 하루 5회 / PRO 60회
- **아침 브리핑** (무료): 오늘·내일 일정을 쉬운 문장으로, 🔊 소리로 읽어 줌
- **카톡으로 보내기** (로그인 없이): 일정을 링크로 보내면 받은 사람이 눌러서 자기 폰 알람에 추가 (내 집 출발로 바꿔 추가 가능)
- **로그인 · 가족 공유** (카카오): 여러 기기 동기화, 가족 그룹(초대 코드), 내 일정을 가족에게 공유 → 가족 폰에서도 알람 (예: 엄마 병원). Supabase `mp_` 테이블 + 행 단위 보안
- 카카오맵·티맵·카카오T 바로 열기, 월간 캘린더, 키 없이도 동작하는 추정 모드

## API 키
**권장**: 키를 앱에 넣지 않고 Supabase 함수 `myplanner-route`(버디플래너 프로젝트에 배포됨)가 대신 조회합니다. 설정 방법은 `docs/launch-guide.md` 2번.

`js/config.example.js`를 `js/config.js`로 복사해 키를 넣으세요. (config.js는 깃허브에 올라가지 않음)

| 키 | 발급처 | 용도 |
|---|---|---|
| `ODSAY_API_KEY` | lab.odsay.com | 버스·지하철 경로 |
| `TMAP_APP_KEY` | openapi.sk.com (버디플래너 키 재사용 가능) | 자가용·택시·도보, 장소 검색 |
| `KAKAO_REST_KEY` | developers.kakao.com | 장소 검색 (티맵 키 없을 때) |

- ODsay 콘솔에서 앱 플랫폼으로 등록할 때, Capacitor 앱의 웹뷰 주소 `https://localhost`를 URI로 함께 등록해 두세요.
- 키가 없어도 앱은 거리 기반 추정치로 동작하고, 화면에 "추정" 표시가 나옵니다. 앱 안의 **설정 > 개발자 설정**에서 키를 임시로 넣어 테스트할 수도 있습니다.

## 실행 · 빌드
```bash
# 웹으로 확인
npx serve .            # 또는 python -m http.server

# 안드로이드 앱
npm install
npx cap add android    # 처음 한 번
npm run android        # www 빌드 → 동기화 → 안드로이드 스튜디오 열기
```
`npm run cap-sync`가 끝나면 `scripts/install-native-alarm.js`가 자동으로 실행되어
전체 화면 알람 자바 파일 복사, MainActivity 플러그인 등록, AndroidManifest 권한(정확한 알람·전체 화면·부팅 후 복구) 추가까지 해 줍니다. 여러 번 실행해도 안전합니다.

처음 설치 후 앱의 **설정 > 알람 점검**에서 ⚠️ 항목의 [설정] 버튼으로 권한을 켜 주세요.
- 알람 및 리마인더 (안드로이드 12+): 정확한 시각에 울림
- 전체 화면 알람 (안드로이드 14+): 잠금 화면 위 알람 화면
- 삼성 휴대폰: 배터리 > 백그라운드 사용 제한에서 마이플래너 제외 권장

알람은 앞으로 45일치 계획을 폰에 저장해 두고, 폰이 3일치씩 예약·매일 새벽 보충합니다. 앱을 열 때마다 계획을 새로 넘겨 45일이 계속 이어집니다.
아침 실시간 재계산은 **티맵 키가 있어야** 동작합니다 (버스·지하철은 시간표 기반이라 재계산 대상이 아님).
